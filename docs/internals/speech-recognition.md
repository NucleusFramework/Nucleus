# speech-recognition internals

`speech-recognition` - Streaming speech-to-text, a **Kotlin Multiplatform** library module (jvm / android / iosArm64 / iosSimulatorArm64; iOS klibs cross-compile on any host). Desktop = Rust JNI bridge (`nucleus_speech`) over `robius-speech` (git dependency pinned by `rev`: SAPI on Windows, its Swift SFSpeechRecognizer bridge on macOS; Linux ships no library and is unsupported); Android and iOS are Kotlin ports of robius' Java/Swift backends. Like `share`, the module keeps the JVM JNI layout (`src/main/native`, `src/main/resources` added to `jvmMain`), which `nucleus.native-module` wires into `jvmProcessResources`. Common code owns the session rules (one live session, terminal event removes it, late callbacks dropped: `SpeechSessions`), `Dictation` (port of `dictation.rs`, **UTF-16** offsets instead of bytes) and `TranscriptSegments` (the Swift `SegmentTracker`, kept common so it is unit-tested on the JVM). K/N gotcha: Objective-C category members (`AVAudioSession.setActive`, `NSLocale.localeIdentifier`) are extension functions that need an explicit import. Notices: THIRD_PARTY_NOTICES §6, shipped in the JVM JAR and the AAR. `-Dnucleus.speech.live=true` on `jvmTest` opens the real microphone (Windows/macOS)
