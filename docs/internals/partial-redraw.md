# Partial redraw (#755)

**Partial redraw** (#755, Linux, Windows, macOS; **opt-in** with `nucleusOptimization { partialRedraw = true }`, also on under the `nucleusOptimization = true` master): a frame repaints and presents only what changed. The knob registers the Compose patch below (off, Compose is not transformed at all), adds `-Dnucleus.tao.partialRedraw=true` to `jvmArgs` and bakes `optimization.partialRedraw=true` into `nucleus-app.properties` for native images (`PartialRedraw.enabled`: the system property wins, else that key; off by default). Linux: buffer age (`EGL_EXT_buffer_age`) + `eglSwapBuffersWithDamage`, the damage history in `DamageHistory`. Windows: ANGLE's window surface is its own offscreen texture, kept with `EGL_BUFFER_PRESERVED` (buffer age always 1), presented with `eglPostSubBufferNV` — ANGLE copies only the damaged rectangle into the blt swap chain and passes it as the `Present1` dirty rect; damage drawn but not presented accumulates in `pendingPresentDamage`. ANGLE 8037 has no copy-free path (the experimental fast present path needs `EGL_ANGLE_surface_orientation`, gone: `EGL_BAD_ATTRIBUTE`). macOS: per-drawable damage (`MetalDrawableDamage`, IOSurface ID). A repaint covering ≥ 80 % of the frame is done in full on macOS and Windows (`PartialRedraw.FULL_REPAINT_PERCENT`, measured break-even on both: a partial frame has a fixed cost). Damage is per **render layer** (HWUI's `DamageAccumulator` granularity): `LayerDamageTracker` walks the layer tree between layout and draw (`TaoSceneBundle.render(beforeDraw)`, `TaoSceneRenderingScope` = Compose's `SingleComposeSceneRenderingScope` with that hook) and compares each layer's content version, property fingerprint and window footprint with the previous frame. Compose keeps a layer's dirtiness private, so the plugin patches it in (`LayerDamageTransform`, an artifact transform like the LCD one): a counter on `GraphicsLayerOwnerLayer` (`invalidate` / `triggerRepaint`) read through the generated `NucleusLayerDamage`, and `GraphicsLayer.record` / `draw` hooks (`NucleusGraphicsLayerHooks`) feeding `GraphicsLayerDrawRegistry`, which tells an explicit layer recorded and drawn by the same layer (`rememberGraphicsLayer` + `drawLayer`, followed precisely) from one recorded elsewhere (a backdrop blur: next frame full). The runtime compiles against stubs (`src/composeStubs`, `compileOnly`, never packaged); without the patch (no plugin, IDE run, hot reload) the classes are missing and every frame is full. A footprint is the layer's bounds only when it clips and has no shadow / render effect; otherwise its nearest clipping ancestor's clip. Anything uncertain repaints in full: unknown damage, buffer age 0 or beyond the history, resize / in-frame (#444), foreign GL, clear colour / corner / scrim change (`partialRedrawFrameKey`), more than one owner (a canvas popup open). A frame whose damage is empty is neither drawn nor presented, its successor paced by a timer at the measured present period. Switches: `-Dnucleus.tao.partialRedraw=true|false` forces it (and `NUCLEUS_TAO_PARTIAL_REDRAW=0` native side), `.debug=true` (logs full-frame reasons and repaint stats), `.tint=true` (tints repainted areas), `.verify=true` (oracle: every frame compared with a full render of the same recording, failures are diffs above ±2 or outside the repaint; `.verify.dump=<dir>` writes PNGs). E2E: the Lab's `partial-redraw` fixture, one variant per scene (`-Dpartial.demo.scene=blink|blink-plain|idle|tour`)
