# The Lab and the example apps

`examples/` - **`lab/` is the test bench** (`./gradlew :examples:lab:app:run`, JVM 25, see `examples/lab/README.md`): one app of *probes*, one per capability, MVVM + MVI with Metro DI. Modules: `core` (Probe contract, `MviViewModel` + pure `Reducer`, `Timeline` that flags off-UI-thread callbacks via `Stamped`, `EnvironmentProvider`, `CheckStore` — manual pass/fail per environment fingerprint, `LabCommands` — `nucleus-lab://probe/<id>?k=v` deep links and `-Dlab.probe=` / `LAB_PROBE`, `SessionHost` — probe windows composed at the application root so they outlive navigation, `Fixture` + `FixtureLauncher` — code that must own its process, run by relaunching the Lab with `-Dlab.fixture=<id>` or `--lab-fixture=<id>`), `designsystem`, `probes/{window,workspace,input,rendering,shell,notifications,lifecycle,updater,system,fixtures}`, `app` (graph, shell, Overview/Environment/Coverage, packaging, `nucleus-lab-cli` launcher; the shell dogfoods the satellite workspace: the main window is a `DockLayout` around the selected probe, and the probe list, checks and timeline are `Satellite`s docked left / right / bottom by default, floatable, toggled from the title bar through `ShellState.openPanes`, and their layout is persisted as a `SatelliteLayoutSnapshot` in `shell-layout.json` under `LabPaths.dataDir`, an unreadable file falling back to the default layout). A probe = Contract + Gateway (`@ContributesBinding`) + ViewModel (`@ViewModelKey @ContributesIntoMap(AppScope::class, binding = binding<ViewModel>())` — the `binding` is required, Metro binds to the direct supertype `MviViewModel`) + Probe (`@ContributesIntoSet`); the graph is only assembled by `:examples:lab:app:compileKotlin`. Fixtures that replaced demos: `rect-stress` (#551 sentinel, exit 55), `swing-tao`, `partial-redraw` (scenes as variants), `a11y-surface` (the AX/UIA/AT-SPI CI target, launched by `pre-merge.yaml`), plus the lifecycle ones (launch-agent heartbeat, scheduled task). The Lab is **written in Jewel** (`designsystem` wraps Int UI: `LabTheme.colors` / `.typography`, `Text`, `Icon`/`LabIcons`, Lab windows on `JewelDecoratedWindow`); probes import only `designsystem` + `core`, Material/Jewel only inside *specimens* (`MaterialSpecimen { }` for Material ones; `window.theming` holds the Material 3 + Expressive, Material 2 and Jewel galleries). It is the only app a release publishes, **as a GraalVM native image** (`release-desktop`: `packageGraalvm<Format>` per OS — Linux deb/rpm/AppImage/pacman/snap, Windows x64 NSIS/MSI/portable, macOS arm64 + Intel DMG/ZIP signed and notarized in the build job — except **Windows ARM**, which has no native-image toolchain and ships the JVM build; no universal macOS bundle, App Store PKG, Flatpak or AppX bundle any more), `test-graalvm` builds its native image on every PR, `test-packaging` still packages the JVM build (all formats, ProGuard release; it inherits nucleus-demo's release identity — bundle ID `dev.nucleusframework.demo`, AppX `KDroidFilter.NucleusDemo`, upgrade UUID — because the provisioning profiles and store reservation are issued for it). nucleus-demo and jewel-demo are gone (`release-graalvm` folded into `release-desktop`). Native-image specifics of the Lab: fixtures relaunch the image itself (`JvmCommand.fixture` passes `--lab-fixture=<id>` and only the `-D` flags), the SwiftUI probe's FFM downcalls are declared in `probes/rendering/src/main/resources/META-INF/native-image/…/reachability-metadata.json`; a sweep that opens every probe in the image (`-Dlab.probe=<id>`) is the quick regression check. Other apps beside it: `cmp-demo` (KMP + Android), `share-web-demo` (Kotlin/JS), `benchmark-demo` (JIT-vs-GraalVM-O3, ports under `ports/`), `macos-appex-demo` (a macOS Network Extension `.appex` embedded and signed through `macOS { appExtensions { } }`), `hot-update-demo` (Windows hot update and updater E2E), `tao-native-test` (GraalVM + SLF4J fixture), `fs-watcher-smoke` and `orphan-reflect-smoke` (headless native-image smokes). The `native-proxy` directory on disk is **not** on `nucleus-3.0` (`feat/native-proxy`), and `examples/jni-demo` / `examples/startup-bench` are untracked leftovers — ignore them.
